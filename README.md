# Nyaah Lembur

Prototipe interaktif Nyaah Lembur untuk Android dan Chrome.

## Menjalankan di Chrome

Pastikan Flutter dan Google Chrome sudah terpasang, lalu jalankan dari folder proyek:

```sh
flutter run -d chrome
```

Versi web membuka antarmuka interaktif dari `nyaah-lembur.html`. Aset lokalnya disertakan saat build web.

## Build web

```sh
flutter build web
```
